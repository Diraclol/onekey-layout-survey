# Layout survey for GNG 2101 Group A3.5 one-handed keyboard

Open the GitHub Pages link below to fill out the survey.

- **Public link:** [open the survey](https://diraclol.github.io/onekey-layout-survey/)
- **Team view:** add `#team` to the end of the link for the team view

## Updating the page

Replace `index.html`, then:

```bash
git add index.html README.md
git commit -m "Update survey page"
git push
```

The GitHub Pages site updates automatically.
